Financially Up Individual Engagement SystemDeveloper SpecificationPart 14 - REST API Specification
Purpose
This document proposes REST API endpoints for the Individual Engagement System. The endpoints are designed to support the workflow defined in the Financially Up specification. Endpoint names and payloads are implementation recommendations.
General Standards
Use JSON request/response bodies.
Authenticate protected endpoints with JWT.
Use HTTPS for all requests.
Return standard HTTP status codes.
Log all administrative actions.

Workflow Mapping
Client creates engagement.
Documents uploaded.
Identity verified.
Engagement Schedule generated.
Client signs electronically.
Status changes to Pending Review.
Admin reviews and decides.
Accepted engagements generate Engagement Acceptance Notice.
Security Requirements
Validate all input server-side.
Virus-scan uploaded files.
Restrict admin endpoints by role.
Do not expose TFNs or bank details in responses.
Maintain audit logs for every admin action.
