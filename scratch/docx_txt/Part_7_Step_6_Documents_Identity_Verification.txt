Financially Up Individual Engagement SystemDeveloper SpecificationPart 7 - Step 6: Documents & Identity Verification
Step Objective
Collect all supporting documents required for the selected services and verify the client's identity using one of the approved verification methods. This section is driven by configurable business rules.
Business Rules
Document requests must be generated dynamically based on selected services and client profile.
Document rules must be configurable by administrators without code changes.
Identity verification method is mandatory.
Offer live video before requesting a selfie for remote verification.
Selfie is only required when the approved verification procedure requires it.
If no photo ID is available, alternative evidence and manual review are required.
Biometric verification requires a separate consent.

Identity Verification Flow
Client selects identity verification method.
If Live Video -> Schedule/complete live visual verification.
If Upload ID -> Upload primary and supporting documents.
If Electronic Verification -> Complete approved eID process.
If No Photo ID -> Collect alternative evidence and send for manual review.
If Biometric verification is used -> Require separate consent before continuing.
Security & Storage Requirements
Store uploaded files in private storage.
Do not include ID images in generated client PDFs.
Separate ID images from engagement records.
Restrict access using role-based permissions.
Automatically delete or restrict raw ID/selfie images according to retention policy.
Maintain audit logs for upload, view and deletion events.
Acceptance Criteria
Identity method is mandatory.
Conditional fields appear only when applicable.
Required uploads cannot be skipped.
Alternative identity path works without photo ID.
Biometric consent is required only when biometric verification is selected.
All uploaded files are stored securely.
