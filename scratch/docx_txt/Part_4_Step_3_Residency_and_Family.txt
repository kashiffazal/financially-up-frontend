Financially Up Individual Engagement SystemDeveloper SpecificationPart 4 - Step 3: Residency & Family Information
Step Objective
Collect citizenship, tax residency, spouse and dependant information. This step is highly conditional and determines whether additional residency review is required.
Business Rules
Australian citizenship must always be collected.
Tax residency must always be collected.
Visa questions are only shown when the client is not an Australian citizen.
If residency changed or is uncertain, create an accountant review flag.
Spouse details are only collected when the client had a spouse during the relevant year.
Do not collect spouse identity documents in this form; create a separate engagement if Financially Up will prepare the spouse's return.
Only collect the minimum dependant information required for tax purposes.

Conditional Logic Matrix
If Australian Citizen = Yes → Hide all visa-related fields.
If Australian Citizen = No → Display Country of Citizenship, Visa Status, Visa Subclass, Visa Expiry, Arrival Date and Visa Evidence.
If Tax Residency = Became Resident, Ceased Residence or Unsure → Display residency change questions and create accountant review flag.
If Has Spouse = Yes → Display spouse information fields.
If Prepare Spouse Return = Yes → Create separate spouse engagement after submission.
If Has Dependants = Yes → Display dependant count.
Acceptance Criteria
Visa fields remain hidden for Australian citizens.
Visa fields are mandatory when displayed.
Residency review flag is created when applicable.
Spouse fields are hidden unless required.
Dependant fields are hidden unless required.
