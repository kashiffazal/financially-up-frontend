Financially Up Individual Engagement SystemDeveloper SpecificationPart 16 - Complete Conditional Logic Matrix
Purpose
This document consolidates the show/hide rules and workflow dependencies used throughout the client engagement wizard. It serves as a single reference for implementing conditional logic in Next.js and Ant Design.
Implementation Principles
Evaluate conditions whenever a dependent field changes.
Hidden fields should not be validated.
Clear hidden field values unless business rules require retention.
Create internal review flags where specified.
Server-side validation must enforce the same conditions.

Developer Notes
Use Form.useWatch() or equivalent state management for dependent fields.
Avoid validating hidden controls.
Display clear transition animations when sections appear.
Log automatic review flags for admin users.
Retain an audit history of workflow decisions.
Acceptance Criteria
Every conditional rule behaves consistently.
Hidden fields are excluded from validation.
Review flags are generated correctly.
Navigation reflects current conditions.
Submission is blocked until all active conditions are satisfied.
