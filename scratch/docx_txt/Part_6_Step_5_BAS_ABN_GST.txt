Financially Up Individual Engagement SystemDeveloper SpecificationPart 6 - Step 5: BAS / ABN / GST
Step Objective
Collect information for Sole Trader BAS, ABN and GST services. All sections are conditional and only appear when the corresponding service was selected during Step 1.
Business Rules
Only individual / sole trader information is collected in this module.
Never collect Company, Trust, Partnership or SMSF identifiers in this form.
Display BAS fields only if Sole Trader BAS service is selected.
Display ABN fields only if ABN Application or existing sole trader ABN is relevant.
Display GST fields only if GST Registration service is selected.
Existing ABN must be validated and confirmed as belonging to the individual.
Invalid ABN blocks submission unless manually overridden by authorised staff.

Conditional Logic
If BAS service selected → Show BAS section only.
If ABN Application selected → Show ABN section.
If GST Registration selected → Show GST section.
If Existing ABN entered → Validate checksum and confirm ownership.
If ABR lookup is enabled → Retrieve ABN status, entity name, entity type and GST registration for confirmation.
If ABN belongs to a company, trust or partnership → Stop process and direct user to the Entity Engagement Form.
Internal Actions
Create review flag when ABN validation fails.
Store ABN in protected format.
Record validation status and ABR lookup result.
Do not expose full TFN in logs or generated PDFs.
Acceptance Criteria
Only relevant sections are displayed.
ABN checksum validation works.
Entity ABNs are rejected from this workflow.
Conditional questions appear correctly.
All values are stored successfully.
